# 股票市场扫描规则 — 双策略模拟交易系统

> 基于杨永兴战法（凤雏）和 Serenity 紫苏叶理论 + SEPA（刘秀）的 A 股双策略系统
> 运行期: 2026-06-11 ~ 2026-06-25（两星期模拟验证）

---

## 策略概览

| 策略 | 角色 | 类型 | 时间 | 来源 |
|------|------|------|------|------|
| **凤雏** | 🟢 短线快刀手 | 技术面日筛 + 隔夜套利 | 每日 14:00-14:55 | 杨永兴战法 / 十步尾盘买入法 |
| **刘秀** | 🔵 价值侦察兵 | 基本面周筛 + 趋势模板 | 周日 21:00 / 每日 08:30 | SEPA 过滤法 / 五因子评分模型 |

### 凤雏策略（杨永兴隔夜套利法）

**核心逻辑**：尾盘买入，次日早盘卖出，隔夜套利。

**硬性条件（全部满足才进入评分）：**
- 涨幅 3%~5%
- 量比 > 1.0
- 换手率 5%~10%
- 流通市值 50亿~200亿
- 过去20天有涨停记录

**评分系统（满分 100 + 板块加分）：**
| 维度 | 分值 | 说明 |
|------|------|------|
| 涨幅 | 25分 | 3-5%满分 |
| 量比 | 15分 | >1.5 满分 |
| 均价线上方 | 15分 | 全天在均价线上 |
| 换手率 | 15分 | 5-8%最佳 |
| 流通市值 | 15分 | 80-150亿最佳 |
| 历史加分 | 20分 | 涨停历史+成交量稳定+无压力位 |
| 板块加分 | 0-10分 | 板块排名加分 |

**买入条件**：评分 ≥ 70，每日最多 2 只，单只 ≤ 总资金 15%

**卖出规则**：次日 09:30-10:00 卖出 | 止损 -2% | 止盈 +3%

### 刘秀策略（SEPA 趋势 + 基本面筛选）

**核心逻辑**：周日全量重筛，每日增量检查，中线持有约 1 周。

**五因子评分模型（入池门槛 ≥ 70 分）：**
- 因子① 确定需求（25%）— AI/新能源/国产替代链条
- 因子② 受限供给（25%）— 全球供给瓶颈
- 因子③ 低关注度（15%）— 券商覆盖数
- 因子④ 价值捕获（20%）— 毛利率、定价权
- 因子⑤ 催化剂（15%）— 未来 1-3 月关键事件

## 使用方法

### 每日扫描

```bash
# 凤雏日筛
python run_scan.py --strategy fengchu

# 指定日期
python run_scan.py --strategy fengchu --date 2026-06-11

# 刘秀周筛
python run_scan.py --strategy liuxiu

# 双策略
python run_scan.py --both
```

### 回测

```bash
# 最近10天回测
python run_scan.py --backtest --days 10
```

> **注意**：回测功能使用当前实时数据近似历史数据，仅供参考。
> 精确回测需等 2 周模拟期结束后，对比实际运行数据。

## 双策略对比

### 分配方案

| 设备 | 角色 | 策略 | 执行频率 |
|------|------|------|----------|
| **设备A**（本机）| 凤雏 | 杨永兴日筛 | 交易日 14:00 |
| **设备B**（远程）| 刘秀 | SEPA 周筛 | 周日 21:00 + 每日 08:30 |

### 评价指标

- 总收益率（2周模拟期结束）
- 胜率（盈利交易 / 总交易）
- 最大回撤
- 夏普比率（简易：收益 / 波动）

## 定时任务配置

### 设备A（本机）— 凤雏

```cron
# 每日 14:00 扫描（交易日）
00 14 * * 1-5 cd /path/to/项目 && python3 run_scan.py --strategy fengchu >> logs/cron.log 2>&1

# 每日 15:00 收盘复盘
00 15 * * 1-5 cd /path/to/项目 && python3 run_scan.py --strategy fengchu --review >> logs/review.log 2>&1
```

### 设备B — 刘秀

```cron
# 周日 21:00 全量重筛
00 21 * * 0 cd /path/to/项目 && python3 run_scan.py --strategy liuxiu >> logs/cron.log 2>&1

# 每日 08:30 增量检查
30 08 * * 1-5 cd /path/to/项目 && python3 run_scan.py --strategy liuxiu --incremental >> logs/cron.log 2>&1
```

### 一键配置

```bash
# 配置凤雏（本机）
bash scripts/setup_cron.sh local

# 配置刘秀（远程）
bash scripts/setup_cron.sh remote

# 同时配置
bash scripts/setup_cron.sh all
```
