基于游资大佬杨永兴"隔夜套利法" + 马克·米勒维尼《股票魔法师》SEPA策略的 A 股选股辅助系统，包含双策略模拟交易和回测框架。

## 核心策略

### 🟢 杨永兴隔夜套利法（凤雏）

尾盘买入、次日早盘卖出，隔夜套利。

- **买入**：14:00 扫描，14:30 执行买入
- **卖出**：次日 09:30-10:00（+3%止盈 / -2%止损 / 10:00时间止损，三选一强制执行）
- **持股时长**：严格 ≤ 次日10:00
- **硬性条件**：涨幅 3%-5%、量比 > 1.0、换手率 5%-10%、流通市值 50-200亿、板块排名前3、20天内有涨停记录
- **评分体系**：满分 100 + 板块加分，≥ 70 分买入，全仓单只

### 🔵 SEPA 趋势模板 + 五因子评分（刘秀）

中线持有（约1周），基本面+趋势双重筛选。

- **SEPA 8条件趋势模板**（40分）：均线排列、RS评级、52周高点位置等
- **VCP波动收缩形态**（20分）：识别收敛蓄力结构
- **五因子评分**（40分）：确定需求、受限供给、低关注度、价值捕获、催化剂
- **买入门槛**：≥ 70 分，全仓单只
- **止盈**：+15% / **止损**：-5%

### 🟣 孔明 — 数据聚合与对比复盘

聚合双策略结果，生成对比日报，维护核心池，支持两周模拟期后的最终评估。

## 快速开始

```bash
# 1. 克隆项目
git clone https://github.com/chenhe81/yang-yongxing-strategy.git
cd yang-yongxing-strategy

# 2. 安装依赖
pip install akshare pandas pyyaml requests

# 3. 运行扫描
python run_scan.py --strategy fengchu  # 杨永兴日筛
python run_scan.py --strategy liuxiu   # SEPA周筛
python run_scan.py --compare           # 对比复盘
python run_backtest.py --days 10       # 回测最近10天
```

## 排除清单

| 类型 | 代码前缀 | 原因 |
|------|---------|------|
| 科创板 | 688xxx / 689xxx | 波动过大 |
| 创业板 | 300xxx / 301xxx | 波动过大 |
| 北交所 | 8xxxxx / 4xxxxx | 流动性不足 |
| ST/*ST | 名称含 ST | 退市风险 |

## 买卖规则

### 凤雏（杨永兴战法）
| 条件 | 操作 |
|------|------|
| 次日开盘 +3% 以上 | 市价止盈 |
| 次日开盘 -2% 以下 | 市价止损 |
| 10:00 未达止盈止损 | 时间止损，强制清仓 |
| 不加仓、不扛单、不做T | 铁律 |

### 刘秀（SEPA策略）
| 条件 | 操作 |
|------|------|
| 持仓达 +15% | 止盈卖出 |
| 持仓跌 -5% | 止损卖出 |
| 持有超过 7 天 | 时间止损 |
| 持仓上限 | 全仓 1 只 |

## 回测

# 双策略同时回测
python run_backtest.py --days 20

python run_backtest.py --strategy fengchu --days 10
