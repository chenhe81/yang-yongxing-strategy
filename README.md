# 杨永兴短线战法 + Serenity 紫苏叶五因子模型 + SEPA 趋势策略
# A 股双策略选股辅助工具与模拟交易系统

> ⚠️ **免责声明**：本工具仅供学习研究，不构成任何投资建议。股市有风险，投资需谨慎。

基于游资大佬杨永兴"隔夜套利法" + 原创 Serenity 紫苏叶五因子模型 + 马克·米勒维尼《股票魔法师》SEPA 策略的 A 股选股辅助系统，包含双策略模拟交易和回测框架。

## 核心策略

### 🟢 杨永兴隔夜套利法（凤雏）

尾盘买入、次日早盘卖出，隔夜套利。

- **买入**：14:00 扫描，14:30 执行买入
- **卖出**：次日 09:30-10:00（+3%止盈 / -2%止损 / 10:00时间止损，三选一强制执行）
- **持股时长**：严格 ≤ 次日10:00
- **硬性条件**：涨幅 3%-5%、量比 > 1.0、换手率 5%-10%、流通市值 50-200亿、板块排名前3、20天内有涨停记录
- **评分体系**：满分 100 + 板块加分，≥ 70 分买入，全仓单只

### 🔵 SEPA 趋势模板 + 五因子评分（刘秀）

中线持有（约1周），基本面+趋势双重筛选。
评分满分100分，四部分评分结构：

1. **SEPA 8条件趋势模板**（40分）— 均线排列、RS评级、52周高点位置
2. **VCP 波动收缩形态**（20分）— 识别收敛蓄力结构、量能枯竭
3. **板块与市场环境**（20分）— 短期/中期动能 + 板块排名强度
4. **Serenity 紫苏叶五因子模型**（20分）— 确定需求、受限供给、低关注度、价值捕获、催化剂

| 因子 | 权重 | 考察维度 |
|------|------|----------|
| ① 确定需求 | 25% | AI/新能源/国产替代确定性链条？下游CapEx增长？ |
| ② 受限供给 | 25% | 全球供给瓶颈？产业链壁垒？ |
| ③ 低关注度 | 15% | 券商覆盖数、研报数量（价值洼地挖掘） |
| ④ 价值捕获 | 20% | 毛利率、客户锁定性、定价权 |
| ⑤ 催化剂 | 15% | 未来1-3月关键事件（财报/量产/政策） |

**买入门槛**：≥ 70 分，全仓单只
**止盈**：+15% / **止损**：-5%

### 🟣 孔明 — 数据聚合与对比复盘

聚合双策略结果，生成对比日报，维护核心池，支持两周模拟期后的最终评估。
数据来自凤雏（远程）和刘秀（远程）的输出目录，通过 SSH 拉取到本地聚合。

## 快速开始

```bash
# 1. 克隆项目
git clone https://github.com/chenhe81/yang-yongxing-strategy.git
cd yang-yongxing-strategy

# 2. 安装依赖
pip install akshare pandas pyyaml requests

# 3. 运行扫描
python run_scan.py --strategy fengchu  # 杨永兴日筛
python run_scan.py --strategy liuxiu   # SEPA周筛
python run_scan.py --compare           # 对比复盘
python run_backtest.py --days 10       # 回测最近10天
```

## 排除清单

自动排除以下板块（代码见 src/data_fetcher.py `is_permanently_excluded()`）：

| 排除类型 | 代码前缀/规则 | 原因 |
|---------|--------------|------|
| 科创板 | 688xxx / 689xxx | 波动过大，不适合隔夜套利 |
| 创业板 | 300xxx / 301xxx | 20%涨跌幅，风险不可控 |
| 北交所 | 8xxxxx / 4xxxxx | 流动性不足，买卖价差大 |
| ST / *ST | 名称包含 ST | 退市风险高 |
| 当虹科技 | 688039 | 永久禁令 |

## 数据源与抓取策略

本工具使用多源混合抓取策略，确保数据稳定可用：

- **股票列表**：akshare (`ak.stock_info_a_code_name()`) 获取全市场代码
- **实时行情**：东方财富 push2.eastmoney.com 批量查询 API，每次最多 100 只
- **历史 K 线**：东方财富 push2his KLine API，支持任意天数
- **板块数据**：东方财富板块排行 + 个股板块映射 API
- **降级机制**：requests 失败时自动降级到 subprocess+curl 重试，解决 Python 3.14 urllib3 兼容问题
- **指数行情**：（可选）sina 或腾讯接口备用

数据获取层设计见 `src/data_fetcher.py`。

## 买卖规则

### 凤雏（杨永兴战法）
| 条件 | 操作 |
|------|------|
| 次日开盘 +3% 以上 | 市价止盈 |
| 次日开盘 -2% 以下 | 市价止损 |
| 10:00 未达止盈止损 | 时间止损，强制清仓 |
| 不加仓、不扛单、不做T | 铁律 |

### 刘秀（SEPA策略）
| 条件 | 操作 |
|------|------|
| 持仓达 +15% | 止盈卖出 |
| 持仓跌 -5% | 止损卖出 |
| 持有超过 7 天 | 时间止损 |
| 持仓上限 | 全仓 1 只 |
