## 策略详解

### 🟢 凤雏策略（杨永兴隔夜套利法）— 部署于 10.26.0.7

**核心逻辑**：尾盘买入，次日早盘卖出，隔夜套利。

**每日时间线：**
| 时间 | 动作 |
|------|------|
| 14:00 | 全市场技术面日筛 |
| 14:30 | 候选股评分 ≥ 70 执行买入 |
| 15:00 | 收盘复盘，通知孔明 |
| 次日 09:30-10:00 | 卖出昨日持仓 |

**硬性条件（全部满足才进入评分）：**
- 涨幅 3%~5% · 量比 > 1.0 · 换手率 5%~10%
- 流通市值 50亿~200亿 · 过去20天有涨停记录
- 所在板块当日排名前 3

**评分系统（满分 100 + 板块加分）：**
| 维度 | 分值 |
|------|------|
| 涨幅 3-5% | 25分 |
| 量比 > 1.5 | 15分 |
| 全天在均价线上方 | 15分 |
| 换手率 5-8% | 15分 |
| 流通市值 80-150亿 | 15分 |
| 历史加分（涨停/成交量/压力位） | 20分 |
| 板块排名加分 | 0-10分 |

**买入条件**：评分 ≥ 70，每日最多 2 只，单只 ≤ 总资金 15%
**卖出规则**：次日 09:30-10:00 | 止损 -2% | 止盈 +3%

### 🔵 刘秀策略（SEPA 趋势 + 基本面筛选）— 部署于 10.26.0.5

**核心逻辑**：周日全量重筛，每日增量检查，中线持有约 1 周。

**时间线：**
| 时间 | 动作 |
|------|------|
| 周日 21:00 | 全量重筛，更新基本面池 |
| 每日 08:30 | 增量检查（新闻/公告/财报） |

**五因子评分模型（入池门槛 ≥ 70 分）：**
| 因子 | 权重 | 考察维度 |
|------|------|----------|
| ① 确定需求 | 25% | AI/新能源/国产替代链条？下游CapEx增长？ |
| ② 受限供给 | 25% | 全球供给瓶颈？产业链壁垒？ |
| ③ 低关注度 | 15% | 券商覆盖数、研报数量 |
| ④ 价值捕获 | 20% | 毛利率、客户锁定性、定价权 |
| ⑤ 催化剂 | 15% | 未来1-3月关键事件（财报/量产/政策） |

### 🟣 孔明（本机）— 总览调度

| 时间 | 动作 |
|------|------|
| 15:00-15:30 | 收集凤雏/刘秀本日结果，生成对比日报 |
| 周日 22:00 | 合并两个池，输出下周核心池清单 |
| 每日 | 维护历史数据，跟踪总收益 |

孔明的工作：
1. 从 `output/fengchu/` 和 `output/liuxiu/` 读取结果
2. 生成双策略对比报告
3. 维护全局交易记录和统计
4. 两周模拟结束后输出最终评估

## 快速开始

### 环境要求
```bash
pip install akshare pandas pyyaml requests
```

### 本机（孔明）每日运行
```bash
# 凤雏日筛 + 模拟交易
python3 run_scan.py --strategy fengchu

# 双策略同时运行（需刘秀数据在本地）
python3 run_scan.py --both

# 生成对比报告（从本地输出目录读取已有数据）
python3 run_scan.py --compare
```

### 远程部署（刘秀 / 凤雏）

1. 将项目 scp 到目标机器：
```bash
# 部署到刘秀
scp -r /Users/chenhe/Documents/股票市场扫描规则 chenhe@10.26.0.5:~/

# 部署到凤雏
scp -r /Users/chenhe/Documents/股票市场扫描规则 chenhe@10.26.0.7:~/
```

2. 在目标机器安装依赖后，设置定时任务：
```bash
# 凤雏上
00 14 * * 1-5 cd ~/股票市场扫描规则 && python3 run_scan.py --strategy fengchu >> logs/cron.log

# 刘秀上
00 21 * * 0 cd ~/股票市场扫描规则 && python3 run_scan.py --strategy liuxiu >> logs/cron.log
30 08 * * 1-5 cd ~/股票市场扫描规则 && python3 run_scan.py --strategy liuxiu --incremental >> logs/cron.log
```

3. 结果回传孔明（本机）：
```bash
# 从凤雏拉取当日结果
scp chenhe@10.26.0.7:~/股票市场扫描规则/output/fengchu/candidates/*.json ./output/fengchu/candidates/
scp chenhe@10.26.0.7:~/股票市场扫描规则/data/trades/fengchu_*.json ./data/trades/

# 从刘秀拉取结果
scp chenhe@10.26.0.5:~/股票市场扫描规则/output/liuxiu/reports/*.json ./output/liuxiu/reports/
```
