# 回测引擎迁移到算力中心

## 迁移背景

回测引擎 (src/backtest/) 使用 multiprocessing 做参数网格搜索，24 核 CPU 并行化运行。
凤雏（10.26.0.7, N100 小主机）CPU 资源有限，迁移到算力中心（24核48线程）充分利用算力。

## 迁移内容

| 项目 | 说明 |
|------|------|
| **Worker 脚本** | `macro_analysis/backtest_worker.py`（281 行，新增） |
| **database.py** | `src/database.py` 增加 `os.environ.get("MARKET_DB_PATH")` 回退 |
| **SSH 密钥** | 凤雏 → 算力中心免密连接 |
| **数据同步** | 凤雏每日 15:20 推送 market_cache.db (83MB) |
| **自动回测** | 算力中心每日 15:35 运行 60 天回测 |

## 网络拓扑

| 路径 | 方向 | 状态 |
|------|------|------|
| Mac → 凤雏 (10.26.0.7:22) | ✅ 可达 |
| Mac → 算力中心 (183.131.24.109:3100) | ✅ 可达 |
| 凤雏 → 算力中心 | ✅ SSH 免密 |
| 算力中心 → 凤雏 | ❌ 不通（私有IP） |
